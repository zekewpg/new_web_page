# zekewpg

A simple, mobile-friendly GitHub Pages site with a photographic-style Milky Way background.

## Files

- `index.html` — main page
- `blank.html` — destination page
- `style.css` — responsive styling
- `stars.png` — night-sky background

## GitHub Pages

Upload the contents of this folder to your GitHub repository, then enable GitHub Pages from the repository settings.
